# Data directory

This directory is used for local datasets. NetCDF and other downloaded data files are excluded from Git by the repository's `.gitignore`; do not upload restricted station data, downloaded reanalysis files, or credentials.

## Eye2Sky station dataset (required)

The OLUOL Eye2Sky station dataset is not included in this repository because access and redistribution are subject to the original provider's conditions.

If you are authorised to use the dataset, place the file at this exact path:

```
data/OLUOL.cleaned.nc
```

Both notebooks expect this relative path when launched with the repository root as the working directory.

## CAMS reanalysis files (optional)

The exploratory notebook includes an optional Copernicus Atmosphere Monitoring Service (CAMS) aerosol-species retrieval for 18 June 2022. The retrieval cell saves the result to:

```
data/cams_species_20220618_v3.nc
```

This requires a Copernicus Climate Data Store account, the `cdsapi` Python package, and locally configured CDS API credentials. Keep credentials in your local configuration; never commit them.

A separate optional total-aerosol-optical-depth check looks for:

```
data/cams_aod_20220618_3hr.nc
```

That file is not generated by the aerosol-species retrieval cell. If it is unavailable, the exploratory notebook skips that check.

Downloaded CAMS files are local inputs and are not distributed through this repository.
